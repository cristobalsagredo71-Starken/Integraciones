Análisis del Caso

Tal como muestra el esquema superior, la nueva solución cambia la operación, pasando de un envío a granel a un modelo de filtro estricto desde el origen mediante el equipo In-House.

Beneficios de la Solución

  • Sanidad Financiera: Al asegurar que las órdenes de flete se emitan de forma completa, se eliminan las fugas de facturación y las engorrosas consolidaciones manuales.
  • Tracking por CUD: Habilita el seguimiento directo mediante el Código Único de Despacho, homologando el lenguaje entre los sistemas y mejorando la visibilidad del cliente.

El Problema (Efecto Secundario)

Para lograr estos beneficios, se hace necesario contar con personal In-House permanente para ejecutar las tareas manuales de filtro ("Carga Completa" y "Pallet Rezago"). Al contrastar esto con las bodegas:

  • En San Francisco: Dado el alto volumen, esta exigencia se justifica económicamente.
  • En Redex: El modelo se quiebra. Pagar un recurso In-House exclusivo para gestionar tan pocos bultos y retener un pallet de rezago resulta en pérdida económica directa para Starken.

Propuestas operativas y sistémicas para eliminar la dependencia de personal In-House de Starken en las bodegas del cliente (especialmente crítico para operaciones de bajo volumen), mitigando el problema de las manualidades obligatorias descritas en la pestaña anterior.

1. Homologación de Etiqueta + Autocarga (Transportista)
Alto esfuerzo TI (Cliente) Integración API
Mecánica Operativa

El cliente consume la API de Starken al momento de cerrar su caja. Imprimen directamente la etiqueta final (homologada). Cuando el transportista de Starken llega a retirar, hace el "pinchazo" (escaneo) para crear la nómina y cargar directo al camión.

Casuísticas y Riesgos (Lo que se rompe)
  • Diferencias de Cuadratura: El cliente declara una cantidad de órdenes emitidas, pero el chofer escanea una cantidad menor. La responsabilidad legal y financiera queda en el aire durante el traspaso.
  • Carga Incompleta en el Andén: Si el chofer pincha un bulto (1 de 2) y el segundo no aparece, no puede armar un "pallet de rezago" mientras el camión espera. Traba la ruta.
  • Sobrecarga al Chofer: Pasa de ser conductor a operador logístico validando completitud.
2. Recepción a Granel + Cross-Docking (Hub Starken)
Cambio de Flujo Logístico
Mecánica Operativa

Se retira la carga con la etiqueta nativa del cliente (sin emitir OF previa) y se lleva "ciega" a una planta central o Hub de Starken. El proceso de hermanado, validación de completitud, emisión de etiqueta y armado del pallet de rezago se hace in-house, pero dentro de las instalaciones de Starken.

Casuísticas y Riesgos (Lo que se rompe)
  • Ceguera en Primera Milla: Si se pierde un bulto entre la bodega del cliente y el Hub de Starken, no hay tracking de Starken para responder. Problema de responsabilidad de inventario.
  • Rezagos Físicos en Starken: Los pallets de rezago quedan físicamente en las plantas de Starken. El cliente tendría que ir a buscarlos o pagar flete de retorno por carga incompleta.
  • Aumento de SLA: Agrega un salto y tiempo de procesamiento intermedio antes del ruteo a destino.
3. Kiosko de Auto-Atención (Self-Service)
Hardware + UX Baja Fricción TI Cliente
Mecánica Operativa

Starken instala un "Tótem" (Computador + Lector + Etiquetadora) en bodegas de bajo volumen. El operario del cliente hace el pinchazo. El sistema (pantalla) le indica con colores si el pedido está completo (imprime etiqueta Starken) o incompleto (le indica apartarlo al rezago).

Casuísticas y Riesgos (Lo que se rompe)
  • Dependencia del Cliente: Starken confía en la buena ejecución y voluntad del personal del cliente para separar físicamente los rezagos.
  • Soporte Técnico de Hardware: Mantención de impresoras, reposición de etiquetas térmicas y fallas de red en una instalación que no controlamos.
  • Auditoría: Requiere validación cruzada fuerte al momento de que el chofer retire la nómina generada por el kiosko.
4. Drop-Off (Inyección Directa en Sucursal Starken)
Comercial / Contrato
Mecánica Operativa

Para operaciones con volumen ínfimo, se elimina el servicio de retiro. Se exige que el cliente inyecte (vaya a dejar) la carga a un centro de distribución o sucursal Starken cercana, usando un portal web para pre-emitir la carga.

Casuísticas y Riesgos (Lo que se rompe)
  • Fricción Comercial: Modifica la promesa de servicio (retiro en bodega) por un servicio de sucursal. El cliente podría exigir rebaja de tarifas.
  • Adopción de Plataforma: Obliga al cliente a tener a un operador digitando o emitiendo a través del Portal Starken antes del despacho.
  • Carga Incompleta en Mostrador: La validación de rezago ocurriría en el mostrador de la sucursal de Starken, generando demoras en la atención y fricciones físicas.
